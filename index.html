Your own animated series, made on your PC.

Automation Upload plans, writes, illustrates, voices and edits episodes of your own animated series with AI. You review every episode and publish it to TikTok with one click — nothing goes online without you.

Download for Windows — free How it works

Windows 10 / 11 (64-bit) · free · works with your own AI accounts · all versions

What it does

Series planning

A season plan with recurring main characters. Every episode picks up where the last one ended.

Scripts you control

Read and edit each script as plain text before anything is produced, or let the app approve checked scripts for you.

Consistent illustrations

Character sheets keep faces and outfits the same in every scene. Rejected images are retried and rephrased automatically.

Voices, music and sound

A voice for every character (ElevenLabs or free Microsoft Edge voices), background music and sound effects.

Finished videos

Fast cuts, readable captions, a cover image and normalized loudness — vertical 9:16 or wide 16:9.

Publish after review

Edit title and hashtags, choose who can see the video and post it to your TikTok account. YouTube upload packages included.

How it works

1

Install and add your keys

Install the app and paste your API keys for Anthropic (scripts) and OpenRouter (images). ElevenLabs is optional. You pay these services directly for what you use; the app shows the cost of every episode.

2

Plan a series

Describe your idea, main characters and style. The app writes a season plan and the scripts.

3

Review and produce

Check the scripts, change what you like and start production. Images, voices, sound and editing happen on your PC.

4

Publish

Open “Manage posts”, watch the episode, edit the caption, pick the privacy level and click “Publish to TikTok”.

Automation Upload connects only to the TikTok account of the person who installs it and signs in. It uses TikTok’s Login Kit (user.info.basic) to show which account you post to and the Content Posting API (video.publish) to upload the videos you approve. It never accesses other users’ data, and nothing is posted without your click.

Download AutomationUpload-Setup.exe

You need

  • Windows 10 or 11, 64-bit, about 1 GB free space
  • An API key from Anthropic and OpenRouter
  • Optional: an ElevenLabs key for premium voices
  • A TikTok account to publish (optional)

Install and update

  • Run the installer — no administrator rights needed.
  • If Windows shows “Windows protected your PC”, click More info → Run anyway (the installer is not code-signed).
  • The app tells you when a new version is out. Install it over the old one; your series, videos and settings stay.
  • Uninstall via Windows Settings → Apps.

Privacy policy

Last updated October 18, 2026

Automation Upload is a program that runs on your own computer. We do not run servers that collect or store your data, we use no analytics or tracking, and we do not sell data.

Data on your computer

Your API keys, TikTok sign-in tokens, series, scripts, images, audio, videos, settings and post status are stored only on your computer, in the program folder. You can delete them at any time by deleting that folder.

AI services you choose

When you produce episodes, the program sends prompts, scripts and images directly from your computer to the services you configured with your own keys: Anthropic (scripts and checks), OpenRouter (images; it forwards requests to image model providers), ElevenLabs (voices) or Microsoft Edge text-to-speech (free voices). Their privacy policies apply. We do not receive this data.

TikTok

  • When you connect TikTok, you sign in on TikTok’s own website. The program receives the basic profile information TikTok returns (nickname, username, avatar, allowed privacy levels) only to show which account you post to.
  • Videos, titles and settings are sent to TikTok only when you click “Publish to TikTok”. The program then asks TikTok for the publishing status.
  • To sign you in, the program exchanges a one-time authorization code (and later refresh tokens) for access tokens. Because TikTok’s app secret must not be shipped inside the program, this exchange passes through a small token service we run on Cloudflare Workers. It adds the secret, forwards the request to TikTok and returns the answer to your computer. It does not store or log codes or tokens. Cloudflare processes connection data such as your IP address to deliver the service.
  • We do not access data of any other TikTok user. You can disconnect in the program and revoke access in your TikTok settings at any time.

YouTube

By default the program creates upload packages that you upload yourself in YouTube Studio. If you connect YouTube with your own Google API credentials, uploads go directly from your computer to YouTube and Google’s privacy policy applies.

Update check

When the program starts, it asks GitHub’s public API for the latest version number. GitHub can see your IP address. No other data is sent.

This website

This website is hosted on GitHub Pages. GitHub may process access data such as your IP address in server logs. The website sets no cookies, uses no tracking and loads no fonts or scripts from other servers. Downloads are served by GitHub.
